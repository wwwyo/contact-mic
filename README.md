# contact-mic

コンタクトマイク（圧電ピエゾ素子で物体の振動を直接拾うマイク）を自作する趣味の電子工作プロジェクト。

空気の音ではなく「物の振動」を録る。机を引っかく音、窓ガラスに当たる雨、ギターの表板、自分の喉 — 普通のマイクでは録れない音の世界を、部品代 2,000 円から。

## フェーズ

| フェーズ | 作るもの | 所要時間 | 部品代目安 |
|---------|---------|---------|-----------|
| 1 | パッシブ・コンタクトマイク（ピエゾ + シールド線 + プラグ） | 30分〜1時間 | 〜¥2,000 |
| 2 | バッファプリアンプ（TL072、ブレッドボード → ケース入れ） | 半日 | 〜¥3,000 |

フェーズ1 だけでも音は録れる（シャリシャリした音になる。理由はフェーズ2で解決）。まず 1 を完成させて達成感を得てから 2 に進む。
