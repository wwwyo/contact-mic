# フェーズ2: バッファプリアンプの製作

ゴール: TL072 オペアンプによるバッファ回路をブレッドボードで組み、パッシブ機の「シャリシャリ音」を本来のフラットな音にする。動いたらユニバーサル基板に移してケースに入れる。

## なぜ必要か

ピエゾ素子は電気的には**コンデンサ**（容量 数nF〜数十nF）で、出力インピーダンスが極端に高い。これを PC のマイク入力（入力インピーダンス 数kΩ〜数十kΩ）に直結すると、ピエゾの容量と入力抵抗がハイパスフィルタを形成し、低音がごっそり削れる。

対策は「**10MΩ という高い入力インピーダンスで受けて、低いインピーダンスで送り出す**」変換器 = バッファを間に挟むこと。増幅（ゲイン）は主目的ではない。

## 回路図

TL072 の片側（1回路）だけを使う、単電源 9V のユニティゲイン（増幅率 1 倍）バッファ。

```
                     9V電池
                       │
                 SW（電源スイッチ）
                       │
        ┌──────┬───────┼─────────────┐
        │      │       │             │
      100µF  0.1µF   100kΩ(R1)     8pin V+
        │      │       │             │
        │      │       ├─── 4.5V   TL072
        │      │       │   (中点)    │
        │      │     100kΩ(R2)     4pin V-
        │      │       │             │
GND ────┴──────┴───────┴─────────────┘

信号系:
  入力ジャック Tip ──┬───────────── 3pin (+入力)
                     │
                   10MΩ(R3)
                     │
                    4.5V中点（R1/R2 の接続点。10µF で GND にパスコン）

  1pin (出力) ────── 2pin (−入力) に直結   ← これでゲイン1倍
  1pin ── 10µF(＋極を1pin側) ──┬── 出力ジャック Tip
                               │
                             100kΩ(R4)
                               │
                              GND
  入力・出力ジャックの Sleeve ── GND
```

TL072（DIP-8）のピン配置: 1=OUT1, 2=−IN1, 3=+IN1, 4=V−, 8=V+。5〜7 は 2 回路目（今回未使用。気になるなら 5pin を中点、6pin と 7pin を直結しておくと安定）。

ポイントは 2 つだけ:

- **R3 = 10MΩ** がピエゾを受ける入力インピーダンス。ここが大きいほど低音が残る
- 単電源なので信号の基準を GND ではなく **4.5V（電池の半分）** に持ち上げている。R1/R2 の分圧がその基準を作り、出力の 10µF が直流を切って音声だけ取り出す

## 手順

### 1. ブレッドボードで仮組み

1. TL072 をブレッドボード中央の溝をまたぐように挿す（ソケットは基板移植時に使うので、ここでは IC 直挿しで可）
2. 電源レール配線: 9V スナップの赤→上レール、黒→下レール（GND）。スイッチを挟むなら赤線の途中に
3. 8pin→9Vレール、4pin→GNDレール、レール間に 100µF（＋を9V側）と 0.1µF
4. バイアス中点を作る: 9V→100kΩ→（中点の列）→100kΩ→GND。中点の列から 10µF（＋を中点側）→GND
5. 中点→10MΩ→3pin。入力ジャックの Tip も同じ 3pin の列へ、Sleeve は GND レールへ
6. 1pin と 2pin をジャンパで直結
7. 1pin→10µF（＋を 1pin 側）→出力ジャック Tip の列。同じ列から 100kΩ→GND。出力ジャック Sleeve→GND
8. 配線を回路図と 1 本ずつ突き合わせてから電池を接続

### 2. 動作テスト

1. 出力ジャック→録音デバイス、入力ジャック→フェーズ1 のパッシブ機
2. 録音しながらピエゾを爪で軽くタップ → 大きくクリアな音が出るはず
3. **フェーズ1 の直結と同じ音源（机を引っかく等）を録り比べる**。低音の量が明確に違えば成功

### 3. トラブルシューティング

| 症状 | 原因候補 | 対処 |
|------|---------|------|
| 無音 | 電源・ピン番号違い | テスターで 8-4pin 間が 9V あるか、3pin が約 4.5V かを測る |
| 3pin が 0V か 9V に張り付く | バイアス系の配線ミス | R1/R2/R3 の接続列を確認 |
| ハムが大きい | GND 浮き・シールド未接続 | ジャック Sleeve→GND を確認。ブレッドボードのうちはある程度は仕方ない（ケース化で改善） |
| 音が小さい | これはバッファなので正常 | 録音側のゲインを上げる。それでも足りなければ下の改造へ |

### 4. （任意）ゲインを持たせる改造

音量が欲しければ 1-2pin の直結をやめて: 2pin→10kΩ→GND ではなく **2pin→10kΩ→10µF→GND、1pin→100kΩ→2pin** とすると約 11 倍。まずはユニティで使ってから判断する。

### 5. ユニバーサル基板への移植とケース化

1. ブレッドボードの配置をそのまま写す気持ちで、ユニバーサル基板にソケット・部品をはんだ付け（部品面の配置を先に決め、裏をスズメッキ線かはんだブリッジで配線）
2. 1 ブロック配線するごとにテスターで導通確認すると、最後にまとめてデバッグするより速い
3. ケースに 3.5mm ジャック 2 つとスイッチの穴を開けて固定。**金属ケースなら GND をケースに落とす**とシールドになりハムが減る
4. 完成したら再び録り比べテスト
