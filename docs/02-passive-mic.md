# フェーズ1: パッシブ・コンタクトマイクの製作

ゴール: ピエゾ素子 + シールド線 + 3.5mm プラグだけの「受動型」コンタクトマイクを作り、実際に音を録る。所要 30 分〜1 時間。

## ピエゾ素子の構造を知る

圧電スピーカーは真鍮の円盤（外周）の上に白いセラミック（中央）が貼られた構造。振動が加わるとセラミックが歪んで電圧が発生する — スピーカーの逆動作でマイクになる。

- **中央の白いセラミック面** → 信号（+）。シールド線の**芯線**をつなぐ
- **外周の真鍮面** → GND（−）。シールド線の**編組シールド**をつなぐ

## 手順

### 1. シールド線の端処理（両端とも）

1. 外側の被覆を端から 20mm 剥く（ワイヤーストリッパー推奨。ニッパーなら刃を軽く当てて一周させ、引き抜く）
2. 現れた編組シールドを指でほぐして片側に寄せ、1 本に撚る
3. 内側の芯線の被覆を 5mm 剥く
4. 芯線・シールドの先端それぞれに**予備はんだ**（はんだを薄く染み込ませる）をしておく

### 2. ピエゾ素子へのはんだ付け

**最重要注意: セラミックは熱で割れる・剥がれる。こてを当てるのは合計 1〜2 秒まで。** 失敗前提で予備を買ってあるので、割れたら気にせず次の 1 枚へ。

1. ピエゾをマスキングテープで作業台に固定する
2. セラミック面の端（中心ではなく縁に近い位置）に、はんだを米粒の半分だけ**先に**盛る。こては一瞬で離す
3. 予備はんだ済みの芯線をその上に置き、こてで 1 秒押して溶かし合わせる
4. 真鍮の外周も同様に: 先にはんだを一点盛り（真鍮は熱が逃げやすいので、こての設定温度があるなら 350°C 程度でさっと）→ シールド線を溶かし合わせる
5. 軽く引っ張って取れないことを確認

### 3. ストレインリリーフ（補強）

はんだ部は引っ張りに弱い。グルーガンで、はんだ付け部とケーブルの根元をまとめてピエゾに接着する。これをやらないと数回の使用で断線する。

### 4. 3.5mm プラグへのはんだ付け

1. **先にプラグの金属カバーをケーブルに通しておく**（はんだ後に通し忘れに気づくのが定番の失敗）
2. プラグの端子は 3 つ: 先端 = Tip（L）、中間 = Ring（R）、根元の大きい金具 = Sleeve（GND）
3. 芯線を **Tip と Ring の両方**にはんだ（モノラル信号を左右両チャンネルに入れるため。届かなければ Tip だけでも可 — その場合録音は左チャンネルのみになる）
4. シールドを Sleeve にはんだ。Sleeve の爪でケーブル被覆をかしめて補強
5. テスターの導通モードで確認: 芯線側とセラミック面が導通・シールド側と真鍮面が導通・**Tip と Sleeve が短絡していない**こと
6. 金属カバーをねじ込む

### 5. テスト

1. 録音デバイス（[04-recording.md](./04-recording.md) 参照）に挿す
2. ピエゾを机に置き、テープで軽く固定して、机の天板を指で引っかく
3. 録音アプリのレベルメーターが振れれば**完成**。録って再生してみる

音がシャリシャリして低音がスカスカでも正常。それはインピーダンス不整合によるもので、フェーズ2 のプリアンプで直る。オーディオインターフェースの Hi-Z（ギター）入力に挿すと、この時点でも太い音が出る。

### 6. コーティング（任意・後日でも可）

プラスティディップにピエゾごと 2〜3 回ディップして乾かすと、防振・防水・耐久性が上がる。コーティング前後で同じ音源を録って聴き比べると面白い（高域が少し落ち着く）。

## トラブルシューティング

| 症状 | 原因候補 | 対処 |
|------|---------|------|
| 完全に無音 | プラグ短絡 / はんだ剥がれ | テスターで導通確認。Tip-Sleeve 間が導通していたら短絡 |
| ブーンというハム音が大きい | シールド未接続 / GND 浮き | シールド線側の導通を確認。ケーブルを手で握ってハムが減るなら GND 系の問題 |
| 触ると音が出るが振動を拾わない | ピエゾの固定不足 | 対象物にテープや両面テープで**密着**させる。押し付けの強さで音が激変する |
